# v0.0.81

## Claude 虚拟首响应

- 网关组开启“提前建立流并保活”与“sub2api 首字统计兼容”后，Claude `/v1/messages` 流式文本请求发送标准 Anthropic `ping` 数据事件。
- 已审查的 sub2api 原生 Messages 转发路径会将该事件计入首响应时间，并在完整事件边界刷新到下一层；Claude 无需额外开启合成空格选项。
- 不伪造回答内容、消息 ID、模型或用量；本网关继续按真实上游输出记录 TTFT，执行真实首字预算、响应校验和失败换源。其他代理或协议转换路径可能过滤 ping，需按实际链路验证。
- 补充双层 HTTP 转发、超时、客户端取消、三种上游协议转换、正则拒绝换源和真实用量回归测试。

## 上游连接恢复

- 为复用的 HTTP/2 连接增加空闲 PING 检测与阻塞写入期限，避免异常连接长期影响后续请求。
- 模型列表查询按上游地址与代理配置使用独立连接池，避免生成连接阻塞模型同步。
- 模型列表 GET 遇到传输或正文读取失败时，在原有 30 秒总预算内换新连接重试一次；HTTP 错误、非法模型 JSON 和用户取消不额外重试。
- 保留每次模型查询尝试的 API 审计；生成请求继续沿用已有换源与计费流程。

无需数据库迁移。相关说明见 [首包保活](../stream-preconnect.md) 与 [上游连接健康](../upstream-connection-health.md)。
