# v0.0.51 — 网关首包保活、价格同步与每日报表

## 新增

- **网关组首包保活**：在编辑网关组中独立开启，设置 0–60000 毫秒随机延迟；先发送 HTTP 200 和 SSE 注释，等待期间保活，真实响应更快到达时不延迟转发。默认关闭。
- **模型价格同步**：可从 sub2api 模型价目源一键同步，支持上下文价格档位及缓存价格差异；价格覆盖保存后，通过可恢复的后台任务重新计算历史记录的展示成本。
- **渠道路由模型映射**：单条渠道路由的支持模型设置可配置模型映射，模型发现与转发使用一致规则。
- **每日报表**：汇总今日、昨日的渠道及源分组消费、请求量、模型分布和缓存命中数据，方便核对消耗及补货。

## 修复与保护

- 修正使用记录表格列错位，并在延迟信息中显示 TPS。
- 保留已结算金额，包括合法的零元结算；历史价格重算不重复扣除用户额度。
- 首包保活与真实首字统计分离，不虚构内容、Token 或计费，不关闭首字超时，也不阻止网关内换源重试与响应校验。
- 补充配置、迁移、价格重算、报表、转发与并发回归用例，并接入 GitHub CI。

## 首包保活使用注意

- 仅作用于流式文本请求；非流式、媒体生成和 WebSocket 不启用。
- 提前返回的 HTTP 200 仅表示建立流连接，不代表模型调用成功。之后若所有上游失败，返回协议对应的 SSE 终端错误；部分下游 SDK 不会对此自动重试。
- 功能不缩短真实模型生成时间。建议先对目标客户端验证流内错误处理，再逐组开启。
