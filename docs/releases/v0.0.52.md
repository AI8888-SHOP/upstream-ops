# v0.0.52 — 首字统计兼容与渠道利润报表

## 新增

- **sub2api 首字统计兼容**：网关组编辑中增加独立开关，沿用首包保活的随机毫秒区间；在符合条件的 Responses 请求中，提前发送生命周期事件和空 reasoning 项，无需修改 sub2api 源码。
- **网关组卖出倍率**：可为每个网关组填写卖出倍率，每日报表展示估算收入、渠道利润及未配置收入的请求数量。
- **历史利润估算**：报表按当前卖出倍率重算历史估算收入，扣除对应上游尝试成本；不改变原有密钥扣费或重复结算。

## 兼容与保护

- 首字统计兼容默认关闭，只对入站 `/v1/responses` 的流式文本、明确 `store:false`、无会话续接及后台模式的请求启用；不符合条件时保留普通 SSE 注释保活。
- 适用于 sub2api 的 `semantic` 统计口径；`visible` 仍等待真实可见输出。该功能不加速实际模型生成，也不保证其他下游采用相同统计规则。
- 兼容模式使用网关生成的响应 ID，不能用于后续 `previous_response_id` 续接或查询上游响应；真实文本、工具参数和 Token 用量保持原有内容。
- 对后续流的事件序号、输出索引和响应身份保持一致；清除 SDK 在后续请求中回传的专用空 reasoning 项，不清除真实推理或工具历史。
- 保留真实首字超时、响应校验、换源重试和赢家结算判断；截断、格式异常或矛盾终态不能误记成功或作为成功请求扣费。
- 提前返回 HTTP 200 仅表示流连接已建立；所有上游失败后仍以 SSE 终端错误结束，客户端应检查流内错误。

## 利润口径

- 收入为成功交付请求的标准结算费用乘以网关组当前卖出倍率，包含虚拟缓存调整、去除上游倍率。
- 利润扣除全部上游尝试成本，包括失败或被拒绝的尝试；金额是估算值，不是实际收款或上游账单。
- 卖出倍率留空表示未配置，0 表示免费；保存后可影响历史报表估算，不改动实际额度。

## 构建与升级

- 编译、测试与发布在 GitHub Actions 执行，本机不编译。
- 保持现有网关组的兼容开关关闭；新增字段随程序正常数据库迁移初始化。
- 本次发布不自动部署到既有服务器，也不修改线上网关组设置。

详见 `docs/stream-preconnect.md` 和 `docs/daily-report.md`。
